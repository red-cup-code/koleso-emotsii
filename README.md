# Колесо емоцій

Інтерактивне колесо зі 130 українськими назвами. Учасники вибирають одну або кілька емоцій і підтверджують вибір кнопкою «Зарахувати голос». Кожна вибрана емоція отримує один голос. Режим «Статистика» показує спільний рейтинг і підсвічує популярні сектори.

## Завантаження на GitHub

Створіть репозиторій і завантажте в його корінь вміст цієї папки. Файли `src/` містять сторінку й серверний код, а `migrations/` — схему бази. Нова база починає з нуля.

Для спільного підрахунку цей проєкт використовує Cloudflare Workers і D1. GitHub зберігає код, а Cloudflare запускає сторінку та API. GitHub Pages розміщує статичні файли й самостійно не запускає цей API. [Про GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

## Розгортання

Потрібні обліковий запис Cloudflare і актуальна LTS-версія Node.js. Виконайте команди з кореня папки.

1. Увійдіть у Cloudflare та створіть базу.

   ```sh
   npx wrangler@4 login
   npx wrangler@4 d1 create koleso-emotsii
   ```

2. У `wrangler.json` замініть нульовий `database_id` на ID створеної бази. Якщо вибрали іншу назву бази, оновіть також `database_name`.

3. Застосуйте міграції та опублікуйте застосунок.

   ```sh
   npx wrangler@4 d1 migrations apply DB --remote
   npx wrangler@4 deploy
   ```

4. Відкрийте адресу `workers.dev`, яку покаже команда публікації. Це посилання можна надіслати учасникам.

[Команди Wrangler для D1](https://developers.cloudflare.com/d1/wrangler-commands/) · [Конфігурація Wrangler](https://developers.cloudflare.com/workers/wrangler/configuration/)

## Скидання статистики

У цій версії кнопку скидання за замовчуванням бачать усі відвідувачі.

- `"PUBLIC_STATS_RESET": "true"` у `wrangler.json` відкриває кнопку всім відвідувачам. Після підтвердження будь-який відвідувач може видалити всі накопичені голоси.
- `"PUBLIC_STATS_RESET": "false"` дає змогу захистити скидання кодом адміністратора. Після першого розгортання збережіть довгий випадковий код командою `npx wrangler@4 secret put STATS_RESET_TOKEN`. Кнопка попросить цей код при підтвердженні. За відсутності коду кнопка прихована.

## Локальний запуск

Після створення конфігурації застосуйте міграції до окремої локальної бази й запустіть застосунок.

```sh
npx wrangler@4 d1 migrations apply DB --local
npx wrangler@4 dev
```
