# Колесо емоцій

Інтерактивне колесо зі 130 українськими назвами. Учасники вибирають кілька емоцій і підтверджують вибір кнопкою «Зарахувати голос». Режим «Статистика» показує спільний рейтинг і підсвічує популярні сектори.

[Відкрити колесо на GitHub Pages](https://red-cup-code.github.io/koleso-emotsii/)

## Підключення спільної статистики

Сторінка публікується з `main:/docs`. Для голосування вона звертається до Supabase.

1. Створіть проєкт у [Supabase Dashboard](https://supabase.com/dashboard).
2. Відкрийте SQL Editor, вставте весь файл [supabase/setup.sql](supabase/setup.sql) і виконайте його один раз. Він створює нову базу голосів і три функції для голосування, читання статистики та скидання.
3. У [docs/config.js](docs/config.js) заповніть `projectUrl` та `publishableKey` значеннями з проєкту Supabase. Сюди можна записувати лише публічний ключ. Збережіть зміни в гілці `main`, щоб GitHub Pages оновив сайт.
4. Відкрийте опубліковану сторінку та перевірте статистику після тестового голосування.

Коли база підключена, **будь-який відвідувач** може проголосувати, переглянути результати або скинути всі голоси після підтвердження.

[Документація Supabase Data API](https://supabase.com/docs/guides/api)

## Збірка сторінки

Після змін у `src/` запустіть `node build-pages.mjs` і збережіть оновлені файли в `docs/`. Команда зберігає наявний `docs/config.js`.
